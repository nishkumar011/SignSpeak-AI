# SignSpeak AI

AI-powered Indian Sign Language to Speech Translator.

## Description
SignSpeak AI uses computer vision and machine learning
to recognize Indian Sign Language signs and convert
them into spoken communication.

## Objectives
- Real-time sign recognition
- Text translation
- Speech generation
- Web and desktop support

## Technology Stack
- Python
- FastAPI
- React
- Tailwind CSS
- Electron
- OpenCV
- MediaPipe
- Machine Learning
